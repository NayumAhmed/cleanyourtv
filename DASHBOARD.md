## Recommended workflow

1. Read the quick-start instructions before connecting to a TV.
2. Confirm your exact TV model and firmware where possible.
3. Review a debloat list before applying it, and keep the matching restore path available.
4. Run the repository's checks before proposing changes.
5. Keep changes focused and document any device-specific behavior.
